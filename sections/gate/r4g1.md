# r4g1: Gate Check

The gate ensures that preconditions are met before any tool execution.

## Types
- `GateStatus`: Enum { `Allowed`, `Denied(Reason)` }
- `GatePacket`: Struct { `section`, `function`, `read`, `do`, `write`, `next`, `rail` }

## Functions
- `check_gate(packet: GatePacket) -> GateStatus`: Evaluates the `GatePacket` against current gate rules to determine if the tool may run.
- `dispatch_tool(packet: GatePacket)`: Calls `check_gate` and executes `packet.do` only if the result is `Allowed`.

## Invariants
- `check_gate` must return `Allowed` before the tool in `do` is invoked.
- The gate is a pre-execution check; it does not provide mechanisms to cancel or undo writes already performed by a tool.
