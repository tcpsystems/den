# Skill loader

Draft. Source opened: `research/agent-skills.md`. Followed that note's progressive-disclosure rule and refusal to fetch the catalog into the packet. The packet names one matching skill body; it never embeds the catalog.

## Module

A skill is a procedure selected by a section's work. Selection resolves one skill body by its metadata description; it does not select a model. The body loads only after a match. Supporting material is read by explicit path when its procedure reaches it.

## Types

- `SkillRef { name: string, description: string, bodyPath: Path }`: metadata plus a deferred body path.
- `SkillCatalog`: index of skill metadata and body paths; held by the loader, never copied into a seat packet.
- `SkillBody`: procedure text loaded for one matched `SkillRef`.
- `SkillLoadResult = Matched(SkillBody) | NoMatch | InvalidSkill(reason)`.

## Functions

- `indexSkills(root: Path) -> SkillCatalog`: index metadata and paths without loading bodies.
- `matchSkill(catalog: SkillCatalog, section: Section) -> SkillRef | NoMatch`: match the section's work against descriptions; return at most one ref.
- `loadSkill(ref: SkillRef) -> SkillLoadResult`: read and validate only the named body after match.
- `buildPacket(section: Section, result: SkillLoadResult) -> Packet`: include the section and, only on match, that one body.

## Invariants

- The catalog and unmatched bodies never enter the packet; a packet contains zero or one skill body.
- No match means no skill body, not a fallback catalog dump.
- A skill procedure cannot choose a model or dispatch another seat.
- `Section`, `Function`, `Read`, `Do`, `Write`, and `Next` are non-empty before store or first tool; `Rail` may be empty or one human-flipped switch. These are the existing seven fields, not new fields.

## Files

- Loader implementation: `harness/skills/loader` (proposed path).
- Skill body: the single matched path returned by `matchSkill`.
- Packet schema: existing section record; no catalog path is added to the packet.

## Adopt

Adopt progressive disclosure: index descriptions, then load one matching body. Section/Function/Read/Do/Write/Next/Rail remain the sole record fields. A skill match changes Do's procedure only; it does not route the seat or alter Next or Rail.

## Refuse

Refuse injecting the whole catalog, loading every skill body, or using session-start text as a second router. Refuse a skill choosing a model, dispatching a seat, or changing the section's Write, Next, or Rail.
