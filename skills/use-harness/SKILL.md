# Use the harness

Read this file. Then open exactly one reference. Do not load the catalog into the packet.

The model call is a direct model id. OmniRoute is a tool you name. It is not the default path.

## Route

| Intent | Reference |
| --- | --- |
| Remember, recall, back up fast or recent memory | `references/memory.md` |
| Embed, search memory, use the RX 6600 | `references/embed.md` |
| Run a command in a worker VM, join the society | `references/workers.md` |
| Call OmniRoute, Hetzner, Cloudflare, or another named tool | `references/tools.md` |
| Optimise a prompt, evaluate, rediscover, or onboard | `references/optimise.md` |
| Pick the one skill a seat should carry | `../select-skill/SKILL.md` |
| Fill a niche from the map | `../../plan/niches/INDEX.md` |

## Before any write

Section, Function, Read, Do, and Write are filled when the step stores. Rail is empty unless the human flipped it. Next is an id or stop. One tool call, then its result. A child does not write the parent's Write, Next, or Rail.

## Access

Fast and recent memory are read from this machine. The copy on the OmniRoute host is the backup. Skills load one body when the description matches. A worker shell is `smolvm machine exec` on the `harness` network.
