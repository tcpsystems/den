# Optimise

Read this only when the task is to improve the work, not to do the work.

Pick one of these and write the result as a suggestion. Do not rewrite a decided line.

| Job | Do |
| --- | --- |
| Prompt | Cut the packet to the section, one skill body, and the tool list the section named |
| Deep research | Open the cited page. One claim, one URL |
| Deep analysis | Name the function and the invariant it enforces |
| Onboarding | List the route table in `SKILL.md` and the one command that proves the machine is up |
| Rediscovery | Read fast memory, then OpenViking. Say what is stale |
| Communications | One mesh message. No quota talk |
| Evaluation | Two lines: what passed, what failed |
| Improvement | One smaller function, same seven fields |
| Efficiency | Fewer tokens, one fetch, no second copy of the stream |
| Adaptability | The same function on Debian or on this host |
| Solution | The argv and the file path |
