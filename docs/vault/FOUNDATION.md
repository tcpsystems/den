## Memory

Qwen3-Embedding-8B Q6_K stays the embedder. The official card lists Q8_0 at 8.05 GB, which does not fit the 8 GB card at context 8192. The 70.58 MTEB score is the unquantized 8B as of June 2025, not this file. A 2026 secondary page still cites 70.6. That is not a measurement on this machine.

OpenViking stays the long store. The project describes itself as one filesystem for knowledge, memory, and skills. A custom store would copy that. The custom piece that is still worth writing is the exact function-line ledger, and the scope split below.

## Backup

GitHub is the backup of current memory: global, thread, group, session, team, and selector memory for tools, niches, skills, and the other selectors. The live read path is this machine. A seat rebuilds by checking out the backup and, if vectors are missing, embedding the files again.

## Prompt cache

Prompt caching is a prefix match. arXiv:2601.06007 says it cut API cost 41–80% and time to first token 13–31% across providers. Those figures are that paper, not den. The den rule is a stable prefix: identity, one skill body, the tool schema. A change of tool list or model breaks the prefix. The packet stays after the prefix.

## A2A

A2A is an interoperability protocol. Spring AI's `shareState` default sends the parent thread. den's child is a new seven-field packet. A2A can be a door later. It is not the child mechanism.
