# Global memory

Global memory is a principle, a concept, or an analysis framework that more than one seat has used and a second note has kept.

A skill that is used often can be promoted into global memory. The promotion copies the principle, not the skill body. The skill file stays the body that loads on a description match. Global memory does not become an eighth packet field.

A global note is rebuildable. Delete the derived copy and run the backup from the live files. GitHub holds that backup. A seat does not read GitHub to recall.

## Promote

1. The skill was loaded and the check passed more than once.
2. A second note names the principle in one sentence.
3. The sentence is appended under global. The skill path is the source line.
4. The next seat still loads the skill by description. It may read this principle as keep.

## Not global

- A thread fact, a team fact, or a tool result.
- A secret, a key, or a token.
- A vendor score that was not measured on this machine.
