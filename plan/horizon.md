# Horizon

den is a long-horizon harness. A seat can leave and come back. The work is still the same packet, the same branch, and the same memory. Nothing here replaces fox, foxd, or floki. Those sit in the nest. The harness does not become their GitHub history.

## Holds for the life of a project

| Quality | What it means here | Where it lives now |
| --- | --- | --- |
| Reproducible | A check is a command with an exit code. A second run is written down. | `plan/architecture.md` steps 3 to 5 |
| Secure | Limits are copied, not dropped. A match runs a disallowed action against a control we own. | `prompts/seat.md`, `sections/security/match.py` |
| Maintainable | One function, one file, one test. A later note supersedes. Nothing is deleted. | section branches |
| DRY | One slot list. One route skill. One picker. | `internal/console/state.go`, `skills/select-skill` |
| Persistent | Git is the branch. Fast and recent files are local. OpenViking is the long store. | `plan/nest.md`, `skills/use-harness/references/memory.md` |
| Contextual | The packet names Section, Read, and Do. The seat does not invent the want. | `plan/leaders.md` |
| Memory-aware | Explore lists sources. Deep dive returns passages. One crutch per question. | `plan/leaders.md` |
| Model-aware | The packet names a model id. A combo runs only when the packet names it. | `plan/omniroute.md` |
| Token-aware | The leader cuts the prompt to the section, one skill body, and the named tools. | `skills/use-harness/references/optimise.md` |
| Omni-aware | Batch, A2A, and MCP stay off unless `plan/omniroute.md` says yes. Embeddings stay on port 8091. | `plan/omniroute.md` |
| Structure-aware | A named structure from LangChain, LangGraph, Deep Agents, or OpenViking may be used. It does not become the bus. | `plan/structures.md` |

## Loop

Worker, branch, analyse, consider, assess, evaluate, fix, design, implement, evaluate, feedback. Repeat until the change is the smallest one that holds. Then one skill injection, and stop.

That loop is the project. The project sits in the organisation. The organisation sits in the harness. The harness sits on the host.

## Security horizon

Pentest work is a match on a host we own, or on a range named in a written permission. The premise is one sentence of intent. The defense runs the control. The spectator writes both actions. The writeup does not gain steps, payloads, or a way to deploy an attack somewhere else.

Patching is a smaller function plus a test that failed and then passed. Analysis is the unslanted note. The `User context` block comes after, and it is labeled.

## What stays unbuilt

Start and Stop on the controller. WebSocket. QUIC. Workers as this listen address. Sentry, D1, and a second GPU model. Those are slots. A slot is a name until a packet asks for the function and the test.
