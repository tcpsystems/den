# Structure

Written 2026-10-12. Expansion of the locked foundation. Not a second plan. `plan/BASE.md` changes only when two finished notes agree and no lead cuts them.

## What this is

den is one operator, one packet, one skill, one argv call, then a stop. Power is a small loop that a person can read. Effort stays low because the seat does not invent a second loop, a second store, or a second router.

The user, the machine, and the job change what is loaded. They do not change the loop. A workstation with a display on the RX 6600 waits for the embedder. A packet that names OmniRoute may call it. A packet that does not, does not. A niche pack is one skill file. It is not a new runtime.

## What can grow

Growth is a file plus a check. The check is pass or fail on this machine.

| Kind | Where it lives | What a seat may do |
| --- | --- | --- |
| Skill | `skills/<name>/SKILL.md` | Load one, by description, at turn start. |
| Niche pack | `plan/niches/` and one skill | One domain. The index is a path list, not a prompt. |
| Benchmark | a local task with a known pass or fail | Record the row. Do not import a vendor score. |
| MCP server | a stdio process the nest table names | One server, after a scan note says it is present and who maintains it. |
| Ability | one function line in the packet | Run it once. A repeat reads the stored file. |
| Agent | one seat, one packet | Return. The child is a new packet. |
| Note | `plan/analysis/<topic>.md` or `docs/wave/<topic>.md` | One claim. A second agreeing note can move it toward the base. |

Hot reload is a read of `SKILL.md` at the start of the turn. The body is not cached across turns. Auto-injection runs only when the human did not name a skill, and it is lexical. The human pick wins.

## Council

The council is three seats and a human. It is not a model vote and not a chat.

1. **Reader.** Opens the pages and the local files the packet names. Writes the quoted line, the path, and a certainty. A number with no page is invalid.
2. **Critic.** Tries to break the reader's claim against `plan/BASE.md` and the nest table. A wider door than argv, a second store, or a vendor score used as proof here is a fail.
3. **Scribe.** Writes one note. The note says adopt, leave, or cut. It does not merge.
4. **Human.** Merges, or sends the note back. The seat does not merge and does not push.

A tie is a leave. Two notes that agree, with no lead cut, are what changes the base. One enthusiastic draft is not a decision.

The council's job on a research question is the same shape: one question, the sources, the local measurement, the leave-or-adopt line. Deep research is more sources and a tighter note. It is not a longer packet.

## Feedback

One row per turn. It stays on the seat. It is not posted to OmniRoute, and it does not reorder models.

| Field | Value |
| --- | --- |
| Goal | The Function line. It does not change during the turn. |
| Result | `done`, `refused`, `no-progress`, or `cut`. |
| Accomplished | The Write path, or empty. |
| Failure | The control name, or empty. |
| Strength | The field that changed. |
| Downfall | The field that did not change. |

No progress is the same Read plus the same argv returning the stored result, a refused tool, a length-stop, or repaired JSON. The seat records the sign and stops. It does not retry and does not repair.

## MCP

An MCP server is a tool with an owner. Before a packet may name it:

- The binary or the endpoint is on this machine, or the nest table names the checkout.
- A scan note records who maintains it and the one job it does.
- A trusted source is a checkout the human already uses, or a vendor page the reader quoted. A directory listing is not trust.
- A benchmark is one call with a known result. Pass or fail. No score borrowed from the vendor.
- Memory for that server is a selector row: tool, the call that worked, the path of the result. The row does not copy the server's prompt into the packet.
- Context for that server is the one schema the packet needs. The rest of `tools/list` stays out.

Recommendations are one server for the job already named. A second server that does the same job is a leave.

## Reverse engineering and the workbench

When the file is a binary, a trace, or a foreign tree, the seat still uses the packet. The read is the path. The tool is one argv the jail accepts. The note is the evidence: bytes, addresses, or the function the file actually calls. A guess is marked as a guess.

The workbench follows the file. Go gets `gopls` when the packet names a Go file. TypeScript gets the TypeScript server when the packet names a fox or rea file. Rust gets `rust-analyzer` only when the packet names a Rust file. A language server is not started for a file the packet did not name.

Adaptation to a machine is a fact in the note: which GPU has the cable, whether `:8091` answers, whether the hub has seats connected. The loop does not grow a special case for each fact. The seat waits, refuses, or proceeds on the rule already written.

## Usage

| Score | Seat | One local row. Not an upstream post. |
| Review | Council | Reader, critic, scribe. Human merges. |
| Extend | Human, then a seat | Add one file. One check. One note. |
| Commit | Seat | Imperative subject. One file's rule in the body. No merge. No push. |
| Push | Human side of this session | The branch only. `develop` stays the locked line until two notes agree. |

## Leave out

A community catalog inside the prompt. A probability model that picks the skill. A plugin process. A second memory product. A second router. A remote harness that calls the local gateway to save money. Traffic that pretends to be someone else. A vendor benchmark used as a result on this machine. An eighth packet field. A child that inherits the parent transcript.
